# Learning Paths

Structured learning sequences for different skill levels and technology stacks.

## Path Categories

### `/beginner`

- Foundational concepts and first project guidance
- Focus on understanding over speed
- Heavy scaffolding and explanation

### `/intermediate`

- Feature development and pattern application
- Introduction to architecture decisions
- Growing independence in problem-solving

### `/advanced`

- Complex system design and optimization
- Performance considerations and scalability
- Leading and mentoring others

## Path Structure

Each learning path contains:

```
technology-stack-name/
├── overview.md          # Path description and prerequisites
├── milestones.md        # Major learning checkpoints
├── concepts.md          # Key concepts to master
├── projects.md          # Practical application projects
└── resources.md         # Additional learning materials
```

## Learning Path Templates

### Web Development Paths

- Frontend: HTML/CSS → JavaScript → Framework (React/Vue/Angular)
- Backend: Server concepts → API design → Database integration
- Full-stack: Frontend + Backend + Deployment

### Specialized Paths

- Mobile development (React Native, Flutter)
- DevOps and deployment
- Testing and quality assurance
- Performance optimization

## Usage

Paths are activated by the `learning-coach` subagent based on:

- User's current skill level assessment
- Project requirements and technology choices
- Learning style preferences
- Available time commitment
